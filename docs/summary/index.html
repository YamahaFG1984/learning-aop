《AspectJ in Action》图解笔记

这是本仓库随书源码的配套学习笔记：每一章用大白话 + 图解重新讲一遍核心概念， 并把书里 2009 年前后的 AspectJ / Spring / Ant 老代码，替换成 Java 17+ / AspectJ 1.9.x / Spring Boot 3.x / Maven 的现代等价写法。建议按顺序阅读第 1～9 章打基础， 再挑感兴趣的应用章节（10～17 章）阅读。

🔧 本笔记统一使用的现代技术栈

Java 17（或 21 LTS）· AspectJ 1.9.x · Spring Framework 6 / Spring Boot 3.x · Maven + dev.aspectj:aspectj-maven-plugin（或 Gradle + io.freefair.aspectj）· SLF4J + Logback（替代书中的 Log4j 1.x）· JUnit 5。 各页面里遇到書中的旧写法，都会用「书中写法 vs. 推荐写法」对照框标出。
